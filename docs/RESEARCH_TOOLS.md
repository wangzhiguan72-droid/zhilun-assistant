# 研究工具使用与复验

本地v2.59在论文与配套数据核查中提供可选的AI研究工具。默认关闭AI；本地统计及规则路径无需密钥。学校要求先独立预览并确认，DOCX格式比较才使用这些要求。

## 发送范围

- head：最多前2000字符，工具也不能访问尾部。
- evidence：初始跨章节摘录最多24000字符，工具追加补读另限24000字符；同段重复发送也计入。
- full：最多120000字符，超限停止AI而保留本地报告。
- 规则摘要最多1500字符；不发送上传表格的原始数据行。

研究模式最多两次规划请求及一次最终报告，规划每次上限4096 token，最终预算可选4096、8192、16384。实际服务容灾和SDK行为可能增加网络尝试。费用未知时不报零，服务可用性须自行验证。

只允许search、read、stat_recheck。输入只能是当前论文关键词及字符区间，不能提供路径、任意代码或模型编造的统计量。统计复算只检查论文中明确报告的统计量、自由度和p值的一致性；缺失条件不会猜补，不证明研究真实性。字符偏移以提取文本为基准，不是PDF页码。

## 复验

```powershell
.venv/Scripts/python.exe -m unittest research_tools_test research_review_test audit_grounding_test results_test
.venv/Scripts/python.exe scripts/research_model_experiment.py --simulate --output _local_simulation
```

真实模型实验需自有获授权论文和有效服务配置；设置RESEARCH_GATEWAY_API_KEY或MAGPIE_API_KEY，使用脚本的--gateway与--models指定路由。脚本不会分发凭据或模型权重。本次私有模型通道、原论文、源页、身份映射不随开源包提供；公开匿名执行摘要不能让第三方完整重跑历史材料。

本轮3篇既有硕士论文与12个路由主要对照共66案例，53返回最终正文、13调用失败。这是执行记录，不是判断准确率；有新增有效发现，也有漏读与过度推断。含过程修复与模拟控制的77案例不合并成最终质量指标。模拟240行是软件演示，不是真人调查或原论文数据。

历史需求调研口径与当前软件测试分开。所有模型意见和本地提示仍需对照研究设计、原文和原始分析记录核实。
