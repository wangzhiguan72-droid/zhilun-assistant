# v2.59 交付版本识别

软件版本保持 v2.59。2026-10-29 R1 是发布复查标记：仅补充学校格式入口和模型短连接测试的适用范围提示，不增加功能。

学校格式细查优先 DOCX。PDF 主要核对文本和统计报告，不能完整判定字体、字号和行距。连接测试成功只说明本次短请求可用，长文审阅仍受上下文、额度和超时限制；AI 失败时本地报告仍可使用。

参赛完整包包含本地程序、MIT 源码、运行说明、正式报告、演示和匿名证据。下载后先核对旁附 ZIP 的 SHA256，再按包内文件清单核对 exe 和源码。代码提交、源码 ZIP、exe 与完整材料包各有不同哈希，不能相互替代。

公开 GitHub 仓库是项目主页。评审构建以报名平台填写的当次成果链接及 SHA256 为准；旧公开 Release 不能代替本次交付。形成一个本地 commit/tag 不代表已推送、发布、上传或取得赛事回执。上传完成后应以实际分享地址、提取码与访问验证记录更新发布状态，保留历史构建证据。

研究工具支持范围和可复现边界见 [研究工具说明](RESEARCH_TOOLS.md)。调用成功、发现疑点、独立复核和真人效益是不同指标；本项目不以模型返回率作为准确率。
