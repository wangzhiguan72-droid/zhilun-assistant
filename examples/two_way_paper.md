# 不同教学法对学生成绩影响的实验研究

## 3 研究方法

### 3.1 研究设计

本研究采用 2×3 双因素实验设计，考察**性别**（男 / 女）与**教学方法**
（传统讲授 / 翻转课堂 / 混合教学）对学生学业成绩的交互影响。

### 3.2 数据分析方法

采用双因素方差分析（Two-way ANOVA）检验性别与教学方法的主效应
及其交互作用，显著性水平设为 p < 0.05 为显著。
结果显示，性别主效应显著（F(1, 54) = 12.35，p < 0.001），
教学方法主效应显著（F(2, 54) = 18.70，p < 0.001），
二者的交互作用亦达显著水平（F(2, 54) = 9.80，p = 0.002）。
